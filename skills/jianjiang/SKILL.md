# 剪讲

一条口播，配上网上找来的真实画面：说到“美联储加息”，画面就是美联储的声明原文；说到“金饰跌破1200元”，画面就是那条新闻；说到数字，就是一张数据图。画面跟着字切。

默认版式是 `layout: card`：顶部一条大标题（`headline`，镜头里写 `head` 换），中间一张卡片放画面，下面字幕。想要画面铺满，镜头写 `layout: full`。

**分工：你负责“找”和“判断”，jj 负责“抓下来、记住、摆上时间线、渲染、检查”。** jj 没有智能，不替你搜、不替你判断；它保证你抓过的东西都有来源和授权记录、不会重复下载、不会忘记被否掉的理由。

## 开始之前

```bash
sh <本技能目录>/scripts/jj.sh setup     # 找到引擎、检查更新、检查 ffmpeg / yt-dlp / Playwright
```

下文的 `jj` 都是指 `sh <本技能目录>/scripts/jj.sh`。任何时候拿不准下一步，跑 `jj status <项目>`。

## 流程

```
jj init <项目> --script 口播稿.txt      （已有画讲项目：--from <画讲项目>，连配音一起拿）
jj voice <项目> --engine edge           配音（就是 hj voice；付费引擎要用户先确认朗读稿）
jj scaffold <项目> [--pace calm]        切镜头骨架 → shots.yaml（fast 快剪新闻；calm 讲道理、多数据图）
对每个镜头：写 want → 找 → 抓 → 看 → 选
jj check <项目>                         零错误
jj board <项目>                         故事板 → 发给用户 → 用户确认 → jj approve <项目> footage --by "<原话>"
jj preview <项目> --full                自己看节奏（带水印，不用确认）
jj render <项目>                        成片 + 切点检查图
```

## 一个镜头怎么找

1. **先想画面，写进 `want`。** 读这一镜的 `say`，问：观众此刻需要看到什么才信？优先级：
   事件本身的原始材料（声明原文、公告、数据页、新闻标题）＞ 当事人、现场（发布会、交易大厅）＞ 能说明意思的通用画面（K线、钞票）＞ 金句卡。
2. **先查库，再上网。** `jj library 关键词`。库里否过的不要再捡。通用画面（金条、交易屏、钞票）先 `jj stock gold bars`（Pexels / Pixabay 官方接口，云端不会被拦），搜到的页面网址直接 grab。
3. **自由上网找。** 用你自己的搜索和浏览能力：新闻网站、央行和交易所官网、B站、YouTube、图库（Pexels 等）、Wikimedia Commons。搜什么、去哪儿，你决定。搜不到就换关键词、换语言、换网站、换画面思路。搜过的记下来：`jj tried <项目> s07 "关键词" --where 网站 --result "只有2023年的"`。
4. **抓下来：**
   - 图片、视频页面、普通网页：`jj grab <项目> <网址> --as s07 --note "…"`（视频平台用 yt-dlp；网页存截图和正文，输出里会列出页面里的大图和视频，可以再 grab 它们）
   - 引用网页上的原话：`jj snap <项目> <网址> --find "页面上的原文" --as s08`。找不到原文会报错——**截图引用必须是页面上真有的话，不许改写。** 渲染时自动推近、高亮这句。
   - 长视频先下低清版；选定片段后 `jj grab <项目> --hd a031` 只下用到的几秒高清。
5. **看清楚再选：**
   - 视频：`jj look <项目> a031` 出一张带时间的胶片条；`--from 10 --to 16` 细看几秒。`jj hear <项目> a031 --find "加息"` 用文字定位到第几秒。
   - 几个候选：`jj compare <项目> s07` 拼成一张图，重复、太短、横屏、授权问题都标出来。
   - **你要亲眼确认：是不是这件事、这个人、这个日期。** 框架判断不了。
6. **写决定：** 在 shots.yaml 里写 `use`（和视频的 `from`）。不要的 `jj reject <项目> a031 "这是2023年的发布会"`。

**说到数字，优先用数据图：** `use: chart`，数据写在 `chart` 里（`jj help shots`），引擎画、做动画。数字要和口播对得上，`chart.note` 必须写出处。

找不到也有退路：`use: title`（金句卡，用这句口播排版，不需要素材）。金句卡只用在最该停一下的地方，超过三成会被警告。

## 授权

`jj grab` / `jj snap` 自动记来源、作者、日期、许可证，封签，**不能手改**（改了 `jj check` 报错）。许可证分四档：

- 绿：Pexels、Pixabay、Unsplash、CC0、公有领域、美国联邦政府网站、CC BY / BY-SA（自动署名）、自有。直接用。
- 黄：官方机构网站（央行、交易所、世界黄金协会…）。写一下用途。
- 红：授权未知（新闻网站、平台视频）。要用，必须写评论性引用的理由：`jj note <项目> a012 --purpose quote --why "评论的是什么"`。引用要短（单镜不超过 4.5 秒），全片不超过 12 处，故事板上标红请用户拍板。
- 禁：CC 禁商用、禁演绎。不能用。

本地文件只能标 `--license own|ai|unknown`。网上下的东西一律 grab 网址，不要先下到本地再当“自有”。

用户上传、或者在用户电脑上下好的文件：`jj grab <项目> <文件> --source-url <原网址>`，许可证按原网址认，故事板上标“上传·出处待确认”。

**云端抓不到时**（YouTube、B站要登录或把机房 IP 当机器人；部分新闻站 403）：不要想办法绕过网站的拦截。换路：图库走 `jj stock`；官方网站、Wikimedia 直接抓；视频平台的素材请用户在自己电脑上抓（Remote Control，`JJ_YTDLP_ARGS="--cookies-from-browser chrome"`），或者用户下好上传，再 `--source-url` 入库。

## 剪辑的字段（shots.yaml）

`jj help shots` 看全部。常用：`head`（换标题条，换话题时写一次）、`chart`（数据图）、`layout`、`from`（视频从第几秒）、`fit: fill | frame`（裁满竖屏 / 整幅放中间垫模糊底）、`focus`（裁切保哪边）、`crop: [左,上,宽,高]`（只用一块，比如切掉烧进去的字幕）、`pop`（说到这几个字弹大字，必须是原文）、`cut: cut | flash | zoom | whip`、`meme`（表情包）。

骨架的镜头切分可以改：合并就删一行，拆开就复制一行、把 `at` 改成后半句开头的原文，然后 `jj sync`。`say`、`dur` 是只读的。

## 铁律

1. **画面只能由 jj 产生。** 不要自己写脚本剪视频、拼图。
2. **素材定稿要用户的原话。** `jj board` 出的审片页（`out/review/footage-<版本>.png/.html`）发给用户看——发文件，不是贴路径。用户明确同意后才 `jj approve`。换了素材、挪了起点，确认自动失效。
3. **花钱的事不自动做。** 付费配音、AI 生成画面，都要用户先同意。
4. **引用必须真实。** 截图引用用 `jj snap --find` 截原文；视频引用用 `jj hear` 核对原话。
5. 成片发给用户前，先看一遍 `out/cuts.png`（每个切点前后各一帧，黑帧会标红）。
