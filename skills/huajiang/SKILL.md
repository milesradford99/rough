# 画讲

把一段口播做成视频：像一个人站在白板前，一边讲一边画。画面和声音逐字同步。

成片的标准是**体现系统化的思考**：观众看完，记住的是一张图——有哪些东西、它们之间什么关系、结论从哪儿连出来。
不是一页页的要点，不是带插图的字幕。

## 第一步：每次开始工作前

```bash
sh <本技能目录>/scripts/hj.sh setup
```

它会找到引擎（没有就下载）、检查更新、装好依赖，并告诉你之后怎么运行 `hj`。提示“已更新”时，把本文件重新读一遍。
下文的 `hj` 都是指 `sh <本技能目录>/scripts/hj.sh`。

## 第二步：问 hj 现在该做什么

```bash
hj status <项目目录>
```

它会告诉你现在轮到哪个角色、下一条命令是什么。**任何时候拿不准，就跑它。** 还没有项目时：

```bash
hj init <项目目录> --script <朗读稿.txt>          # 只有稿子：之后用 hj voice 配音
hj init <项目目录> --voice <配音材料目录>         # 已有配音（narration.wav + alignment.json）
# 加 --format landscape 做横屏；默认竖屏
```

项目目录由用户指定；没指定就放在当前工作目录下的 `huajiang/<项目名>/`。

## 三个阶段，三份说明

一条片子按顺序过三个阶段。**做哪个阶段，就只读哪一份说明**，不用全读。

| 阶段 | 角色 | 做什么 | 交出什么 | 读 |
|---|---|---|---|---|
| 1 | 配音 | 把稿子变成一条音频和逐字时间表 | `voice/narration.wav`、`voice/alignment.json` | [voice.md](voice.md) |
| 2 | 规划者 | 想清楚这段话讲的是一个什么系统，怎么画成一张图 | `plan.yaml`（用户确认） | [planner.md](planner.md) |
| 3 | 执行者 | 照计划把每一段画出来，出图、出片 | `scenes/*.yaml` → 关键帧（用户确认）→ `out/video.mp4` | [executor.md](executor.md) |

规划者和执行者是两个角色，可以是两个 agent，也可以是同一个 agent 先后扮演。无论哪种，都要守住分工：

- **规划者不写坐标，不碰 `scenes/`。**
- **执行者不改 `plan.yaml`。** 觉得计划有问题，停下来告诉规划者（或用户），不要自己绕过去。

用户提修改意见时读 [revising.md](revising.md)。查某个字段怎么写读 [reference.md](reference.md)。

## 铁律

1. **画面只能由 `hj` 产生。** 不要自己写网页、SVG、canvas、渲染脚本或“预览页”来代替它，也不要用别的视频技能。交付物只有 `hj stills` 的关键帧和 `hj render` 的 mp4。
2. **三道确认，都要用户的原话。**
   `hj approve <项目> script|plan|keyframes --by "<用户原话>"` 只能在用户明确同意之后运行。不要替用户确认，不要绕过闸门。
   - `script`：付费配音之前，用户确认朗读稿的每一个字。
   - `plan`：动笔之前，用户确认分镜计划。
   - `keyframes`：渲染之前，用户确认关键帧。
3. **画面演示口播，不抄写口播。** 板书只写关键词、数字、标签，每条不超过 10 个字。整句话只出现在字幕里。
4. **卡点写口播原文，不写秒数。** `at: "收走一百块税"`。换配音后自动跟随。
5. **`hj check` 零错误才能往下走。** 警告要么修掉，要么如实告诉用户为什么保留；没处理的警告会原样出现在给用户看的分镜计划里。
6. **密钥不进对话。** 需要密钥时，请用户自己设置环境变量；不要让用户把密钥贴给你，不要把它写进文件或命令行参数。

## 命令一览

```bash
hj status <项目>                      # 现在轮到谁、下一步做什么
hj voice <项目> [--engine edge]       # 配音：默认火山引擎（付费，先确认稿子）；edge 免费
hj brief <项目>                       # 逐句时间、停顿、可以直接抄进 at: 的卡点
hj check <项目>                       # 查计划；有场景后连画面一起查
hj plan <项目>                        # 由 plan.yaml 排出给用户看的分镜计划 storyboard.md
hj scaffold <项目>                    # 照计划生成场景骨架
hj layout <项目>                      # 每样东西落在哪儿（线框图）
hj stills <项目> --draft              # 草稿关键帧：带水印，自己检查用，不需要确认
hj stills <项目>                      # 正式关键帧 → 交用户确认
hj render <项目> [--draft]            # 成片 out/video.mp4
hj cover <项目>                       # 封面
hj patterns / hj assets doodles|figure|icons <词>     # 现成的表现手法和素材
```

例子在引擎目录的 `examples/` 里（`hj.sh setup` 会打印引擎在哪儿）：`examples/one-board/` 是一条完整的片子，`plan.yaml` 和 `scenes/` 都有，照它写。
