# 导演手册：怎么让画面有“人味”

写分镜之前读完这一篇。技术上怎么写在 [reference.md](reference.md)，这里只讲怎么想。

## 一、先想清楚你在模仿什么

一个人站在白板前给朋友讲一件事。他会：

- **说到什么，手就画什么。** 不会提前把整板画好，也不会说完半天才动笔。
- **画的是事情本身，不是他说的话。** 讲“钱转了一圈”，他画的是一个圈和一张钱，不会写“钱转了一圈”五个字。
- **在已有的画上继续加。** 圈一下、划掉、加个箭头、在旁边补个数字。板面是慢慢长出来的。
- **板面满了才擦，或者走到旁边一块干净的地方。**
- **手不会停太久。** 哪怕只是在重点上点两下。

观众觉得“没人味”，几乎总是因为违反了上面某一条。

## 二、先讲好一个故事，再画图

逐句配图做出来的是“带插图的字幕”。动手写 YAML 之前，先填项目里的 `outline.md`（`hj init` 会生成）。它问你五件事，答不出来说明还没想清楚：

1. **观众最后记住哪一个画面？** 不是一句话，是一个画面。全片都在为它铺垫。
2. **母图是什么？** 一条片子最好有一张贯穿的图：两个阵营、一条流程、一杆天平、一条被分的收益。第一次出现时把它立起来，之后每次回来（`recall`）都在它上面**加一样东西或破坏一样东西**。观众靠它记住全片的结构。没有母图的片子，是十几张互不相干的图。
3. **谁是角色？** 写进 `cast.yaml`。老板、讲述者、AI、钱，各一个固定长相。
4. **每一段，三层各放什么？** 主体（人和物）、支撑（数字和小账）、批注（出处、名字、倍数）。在提纲里逐段填满这三栏，写分镜时内容就不会单薄。口播里出现的每一个数字、每一个出处，都应该在这张表里有位置。
5. **开头和结尾。** 第一句话落地时板上就要有一个让人想看下去的画面，不要慢慢搭台；最后一句话落下时，板上只多一样东西。

一条片子的画面节奏大致是：**立问题 → 立母图 → 在母图上推演 → 转折（破坏）→ 回到开头的画面收束**。中间每个场景回答一个“然后呢”。

## 三、分镜的做法：先拆论证，再选手法

口播不是一串句子，是一串**论证动作**：抛出一个说法、给理由、举例子、算一笔账、摆数据、转折、推翻、下结论。
画面要表现的是这些动作，而不是句子的字面意思。按下面五步做，分镜的逻辑就不会散。

**第一步：给每一段标出它在干什么。** 拿着 `brief.md`，在每个段落旁边写一个词：设问、流行说法、理由、典故、算账、数据、转折、结论。一个段落通常就是一个场景。

**第二步：给每个论证动作选一种表现手法。** 框架内置了九种手法（`hj patterns`），每种都自带构图和动作编排，你只需要填角色、把步骤卡到口播上：

| 这段话在干什么 | 用哪种手法 | 画面上发生什么 |
|---|---|---|
| 讲钱、货怎么在几方之间转 | `cycle` 循环流转 | 东西沿箭头一站一站滑过去，转回原点 |
| 一环扣一环地讲理由 | `chain` 因果链 | 说到哪环长出哪环；推翻时把一条箭头打叉 |
| 两种情况摆在一起比 | `versus` 两相对比 | 一边一个场面，中间一条线 |
| 一个数被砍、被吃掉 | `bars` 柱子 | 柱子上半截被板擦擦掉 |
| 一个数一路涨 / 跌 | `trend` 走势 | 线跟着口播一段段画到对应的点，关键点标红 |
| 按年代讲 | `timeline` 时间线 | 讲到哪年，轴上长出哪年的画面 |
| “很多人觉得”“他说了一句” | `thought` 想法 | 头上冒泡泡，里面是画；被推翻时泡泡被擦掉 |
| 一句话的等式型结论 | `equation` 等式 | 两个画面中间一个等号 |
| 一份东西怎么分 | `split` 怎么分 | 一整条，一段段涂上颜色 |

手法展开后就是普通元素，可以在同一个场景里加自己的元素和动作（用 `area` 让手法只占一部分画板）。
九种手法都不合适时再从零摆元素——但先想想是不是这段话其实包含两个动作，该拆成两个场景。

**第三步：定角色表。** 全片出现的每个“东西”——你、老板、政府、公司、AI、钱——定一个固定长相，从头用到尾。
老板永远戴礼帽，“你”永远是那个光头小人，钱永远是那张绿钞票。观众靠这个跟上逻辑：同一个东西第二次出现时不用再解释。

**第四步：设计“呼应”和“破坏”。** 这是分镜显得聪明的地方。

- **呼应**：开头立起来的画面，结尾要回来。开头小人对着钞票两眼放光，结尾同一个小人、同一张钞票，但中间隔着一个问号。
- **破坏**：反驳一个说法时，不要另画一张图说“这是错的”，而是回到表现那个说法的画面上，把它打叉、擦掉、把链条掐断。先建立，再破坏，观众才有“原来如此”的感觉。
- **留白**：结论落下的那一刻，画面上应该只多一样东西。别在最重的那句话上同时画三样。

**第五步：卡点。** 卡点决定了“同步感”：

- **名词出现 → 东西落笔。** 说到“政府”，政府开始画。
- **动词出现 → 动作发生。** 说到“收走”，钞票开始滑。
- **数字出现 → 数字写下。** 说到“五十三”，写 53。
- **转折词出现 → 破坏发生。** “可是”“但”“站不住”，叉落下来、泡泡被擦掉。
- 一个场景的最后一拍要在转场前 0.5 秒做完；全片最后一笔要在配音最后一个字之前落定。
- **数字不早也不晚。** 柱子可以先立起来，数值等说到再写（`bars` 的 `col.N` + `value.N`）；别让一个数在口播说到它之前七八秒就挂在板上。
- **先建立，停一下，再破坏。** 要擦掉、划掉的东西，画完至少让它完整地待 1 秒。
- **换板之后马上落笔。** 新板面的第一拍卡在这个场景开口的那几个字上，不要让空板等人。

## 四、信息密度：一块板讲完，应该是一张值得截图的图

画面稀疏会让人觉得内容单薄。“不像 PPT”不等于“少放东西”——真人讲课的白板，讲完一段之后是写满画满的。
目标是：**每个场景结束时，板上是一张信息丰富、可以单独截图发出去的图解。**

把板上的东西分三层，三层都要有：

| 层 | 是什么 | 大小 | 例子 |
|---|---|---|---|
| 主体 | 这段话的主角和它们的关系 | 大 | 公司、政府、你、中间流转的钞票 |
| 支撑 | 让主体站得住的数字和结构 | 中 | 一张小账、一根柱子、一条走势线、“+0” |
| 批注 | 观众想多知道一点的细节 | 小 | 箭头上的“交税”“发钱”、“年利率”、年份、出处、倍数 |

做到这一点的办法：

- **箭头都写小字。** 箭头本身只说“有关系”，小字说“什么关系”：`label: 交税`。手法里用 `flows` / `links`。
- **关键元素加批注。** `{ note: 写进州宪法, target: safe }` 会在目标旁边贴一行小字，用细线牵过去。数字、名字、年份、出处都适合。
- **数字要算给人看。** 说“赚了十块”，板上是 `100 ×10% → 10` 这样一行小账，而不只是一个“10”。
- **一块板放两种手法。** 上半板一个循环，下半板一根柱子；`pattern` 写成列表，各占一块 `area`。
- **少换板。** 能在同一块板上接着加，就不要平移到新板面。换板意味着前面积累的信息全没了。
- **每一拍都加东西。** 主体一拍、小字一拍、批注一拍，画面一直在长。

密度的边界：批注一条不超过十个字；不照抄口播；字号不小于 36。
东西再多也不会互相压住——这一条由引擎保证：压到了它会自动挪开，线会自动绕路。你只需要留意 `hj check` 里“已自动挪开”的提示：如果挪动幅度很大，说明你给的位置本来就不合适，或者这块板已经太满。
检查器会在场景“讲得久、东西少”时提醒你。

## 五、一次做对：用不会出错的写法

事后靠检查器报错再改，是最慢的路。下面每一条，都是把一类错误从“可能犯”变成“犯不了”：

| 要做的事 | 容易出错的写法 | 不会出错的写法 |
|---|---|---|
| 一排人、一堆同样的东西 | 手写十个元素、十组坐标 | `{ crowd: 10, cols: 5, of: {...}, at: [x, y] }`：整体定位，永远对齐 |
| 前面的图再出现 | 把那场的元素抄一遍 | `recall: 场景名`：定义和位置原样带来，进场已在板上，不占口播时间 |
| 同一个角色出现在多场 | 每场各写一遍长相 | `cast.yaml` 定义一次，场景里 `{ cast: boss, ... }` |
| 人站在某样东西上 | 估一个 y 坐标 | `at: boat.deck, anchor: bottom`（手绘件自己声明的锚点） |
| 人走到某处 | `walk … by: [dx, dy]` 再 `hide` | `walk: p6..p10, to: boat.deck`（脚落在那儿，几个人保持队形） |
| 手里拿东西 | 把东西摆在 `小人.handR` | `carry: { doodle: laptop }` |
| 东西挨着另一样东西 | 两边都写绝对坐标 | `rightOf` / `below` / `at: 元素` / 批注 `note` |
| 常见的论证结构 | 从零摆元素 | 先看九种手法里有没有现成的 |
| 数字卡点 | 和柱子一起画 | `col.N` 立柱子，`value.N` 卡在说出数字的那一刻 |

**写完一个场景就看一眼，不要攒到最后。** 位置看 `hj layout`，画面看 `hj stills --draft --scene N`。

 `hj layout <项目> --scene 3` 不画任何笔画，只告诉你每个元素最后落在哪儿：一张坐标表、一张占用图、一张线框图。它不需要用户确认，随时可以跑。看三样：有没有东西被引擎挪走（说明你给的位置不成立）、占用图上有没有一整块是空的、有没有东西挤在一起。`hj check` 开头的清单会列出每个场景三层信息各有几样，哪一层是 0 一眼可见。

**坐标只给“这块板的骨架”。** 先定两三个大件的位置（主体、分隔线），其余的都相对它们摆。一个场景里手写坐标的元素超过六七个，通常意味着该用手法、人群或相对定位了。

## 六、版式：让每一块板都不难看

审美的下限靠几条固定的规矩。不需要每次发挥，照着做就不会丑。

**分区（竖屏 960×1250）。** 先决定用哪种版式，再往里放东西：

| 版式 | 上 | 中 | 下 | 适合 |
|---|---|---|---|---|
| 上图下账 | 0–55%：一个大场面 | — | 60–100%：小账、结论、讲述者 | 大多数场景 |
| 上下对比 | 0–47%：情况 A | 一条分隔线 | 53–100%：情况 B | 两条路、前后对比 |
| 母图 | 0–15%：两个阵营的名字 | 20–70%：母图本体 | 75–100%：这一场新加的东西 | 贯穿全片的那张图 |

板面从上到下都要有东西。检查器会在某一整条横带（板高的 16% 以上）空着时提醒你。

**字号只用四级**，全片一致：

| 用途 | 字号 |
|---|---|
| 大数字、结论性的一个字（“调”） | 110–150 |
| 关键词、阵营名 | 72–100 |
| 标签、小账 | 52–66 |
| 批注、箭头小字 | 40–48 |

**大小分主次。** 一块板上只有一个最大的东西。主角小人 300–420，配角 200–260，人群里的每一个 130–160。同一类东西在全片大小一致（船不要这场 290、那场 165）。

**颜色有含义，而且克制。** 墨色是默认。红色只给三种东西：否定（叉、划掉）、警示的数字、此刻的重点；一块板上红色的字不超过三处，多了就等于没有重点。蓝色给“新的、正面的那一方”。灰色给次要信息和出处。一个概念全片一个颜色。

**留边。** 所有东西离板沿至少 16px。贴边的字看着像被裁了一刀。

**对齐。** 并排的东西底边对齐（都写 `anchor: bottom` 和同一个 y），成行的文字左对齐（`anchor: left` 和同一个 x）。

## 七、每句话问自己三个问题

1. **这句话里的“东西”是什么？** 人、机构、钱、货、机器、时间、数字。每个东西给它一个固定的长相和位置。
2. **这些东西之间发生了什么？** 给、拿、涨、跌、变多、消失、挡住、绕开。这才是要画的——用**移动、箭头、变形、擦除**来表现。
3. **观众此刻该看哪儿？** 用画的顺序、圈、镜头推近来指挥视线。

如果一句话问完三个问题还是只想到“写几个字”，说明还没想透，再想。

## 八、把话变成画的常用手法

| 口播在讲 | 别这样 | 这样 |
|---|---|---|
| A 把钱给 B | 写“A→B 100元” | 画 A 和 B，钞票从 A 手里**滑**到 B 手里 |
| 一圈下来没赚 | 写“净收益为零” | 钞票绕一圈回到原点，原点上写个大大的“+0” |
| 某个数很低 / 在跌 | 写一句结论 | 折线画到那个点，把点涂红，小人吓一跳 |
| 被砍掉七成 | 写“削减 70%” | 先画一根高柱子，再在旁边画一根矮的；或者把高柱子**擦掉**一大截 |
| 有人觉得 / 很多人说 | 写“观点：……” | 小人头上冒一个想法泡泡，泡泡里画个图标 |
| 这个说法站不住 | 写“结论：错误” | 在刚才画的东西上打个红叉，小人摊手 |
| 两件事对比 | 左右各列三条要点 | 左右各画一个场面，中间一条线，同一个小人在两边表情不同 |
| 原因 → 结果 | 写“因为…所以…” | 画出原因，画箭头，再画出结果；箭头落笔卡在“所以”上 |
| 抽象概念（谈判筹码、话语权） | 写出这个词再解释 | 找一个能拿在手里的东西代表它（筹码、话筒、天平），之后一直用它 |
| 时间流逝 / 历史 | 写年份列表 | 画一条时间线，小人沿着线走，走到哪儿画到哪儿 |
| 强调一句金句 | 整句写在屏幕中央 | 把全片出现过的关键画面留在板上，只圈出其中最要紧的那一个；金句留给字幕和声音 |

**板书的正确用途：** 名字标签（公司、政府）、数字（100、53%、+0）、2–5 个字的关键词（“谈判题”）。数字是画面的一等公民，要写大、写醒目。

## 九、小人是讲述者的替身

全片最好有一个贯穿的小人。它不是装饰，它替观众做反应：

- 讲到反常的事 → `face: surprised`
- 讲到“你可能会说” → 小人 `think` 或头上冒问号
- 讲到坏消息 → `slump`、`worried`
- 指向重点 → `point-right` / `point-up-left`
- 得出结论 → `shrug`（无奈）或 `cheer`

姿势和表情的切换几乎不花时间（0.3 秒），是填补“画面静止”最便宜、最有人味的办法。

用配饰区分角色：老板戴礼帽（`tophat`），工人戴安全帽（`hardhat`），学者戴眼镜。同一个角色在全片保持同一套打扮。

小人可以**手里拿东西**（`carry: { doodle: moneybag }`，东西会跟着手走），也可以**真的走过去**（`walk` 动作，边移动边迈步）。“老板提着钱走了”就应该是一个提着钱袋的老板走出画面，而不是一行字。

## 十、节奏

- **一拍只做一件事。** 一拍大约对应半句到一句话（1–2.5 秒）。一拍的时间够画一个主体元素，或者两三样小东西（一个箭头加小字、一条批注、一个数字）。
- **复杂的图拆开。** 三个角色分三拍画，每个角色卡在提到它的那个词上。
- **善用停顿。** `hj brief` 里列了每句后面的停顿。转场、擦板放在停顿里；下一句要画的大东西可以用 `lead` 提前半秒起笔。
- **检查器说“画得太赶”时**，不要只是加 `dur`。问自己：这一拍是不是塞了两件事？这个图是不是能更简单？
- **检查器说“静止太久”时**，那几秒在说什么？给它一拍：小人换个动作、在已有的东西上圈一下、推一下镜头。
- **小动作只能垫一两秒。** 晃一下、换个表情不算往板上加东西；连续十来秒只有这些，观众看到的就是一张不动的图。那段话里一定有能画的东西：一个数、一个对比、一个后果。
- **一群人不要一拍闪出来。** 十个小人分两三拍画，或者用 `lead` 提前起笔。

## 十一、板面与镜头

- 一个场景就是一块板面。一个场景讲一件完整的事，通常 10–30 秒。
- **把板面用满，但不是靠把东西放大。** 主角元素占板面短边的 25%–35%，剩下的地方留给支撑信息和批注。
- 话题延续 → 留在同一个场景里继续加。
- 换话题 → 新场景，`enter: pan`（像走到白板的另一边）。
- 推翻前面的说法、从头再来 → `enter: wipe`（擦掉重画，本身就是一个表态）。
- 板面上东西多、此刻只讲其中一个 → `camera: {focus: [...]}` 推近，讲完 `camera: home` 拉回。
- 同一个东西第二次出现时，尽量长得一样、位置一致。观众靠这个认人。

## 十二、竖屏和横屏

- 竖屏（960×1250 的画板）：上下分区。常见布局是上面一个大场面、下面一行结论；或者从上到下的流程。
- 横屏（1700×800 的画板）：左右分区。适合对比、时间线、从左到右的流程。
- 一份分镜只针对一种画幅。换画幅需要重新摆位置，但 `beats` 基本可以原样保留。

## 十三、交稿前自查

交分镜表之前先跑 `hj stills --draft`（带水印的草稿，不需要用户确认），逐张看联系表，问下面这些问题，改到满意再把 `storyboard.md` 交给用户。用户确认文字分镜、出了正式关键帧之后，再看一遍。

1. 关掉声音只看画面，能看懂大概在讲什么吗？
2. 有没有哪一帧像 PPT（整齐的文字块、居中的标题）？
3. 每一拍和上一拍相比，画面上有没有新东西或新动作？
4. 每个场景的最后一帧，单独截图发出去，别人能看懂、觉得有料吗？
5. 有没有东西太小、互相压住、贴着边？
   **重点看后画的那一层**：圈、框、叉落下之后压到了谁，批注有没有被线穿过。引擎的自动避让管不到标记，检查器会报，但最终要靠你看图。
6. 被引擎自动挪过的元素（`hj check` 里的“已自动挪开”），挪完还在它该在的地方吗？问号还在它问的那个东西旁边吗？一排人还齐吗？
7. 站在别的东西上的小人，脚真的落在上面了吗（用锚点，如 `boat.deck`）？走过去的小人走到了吗？
8. 最后一帧是不是一幅完整的、能代表这个场景的画？
